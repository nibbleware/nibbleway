# Nibbleway

> **Decompose Complexity. Orchestrate Agents.**
> The Precise Path for Digital Intelligence.

**Nibbleway** provides the Architecture & Governance layer for Agentic AI. It allows you to design precise "Blueprints" for your agent workflows and enforce them at runtime.

## Core Components

1.  **The Blueprint**: A declarative definition of your agent system (Agents, Flows, Rails).
2.  **The Rail**: A runtime proxy (MCP) that enforces the Blueprint.
3.  **The Recorder**: A structured logger for observability.

## Getting Started

See `blueprint_schema.yaml` for the definition of an Agentic Architecture.
